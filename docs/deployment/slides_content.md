## 第4页：部署方式对比

### 三种部署方式

| 部署方式 | 优点 | 缺点 | 适用场景 |
|---------|------|------|---------|
| **Docker** | 隔离性好、易扩展 | 学习曲线陡 | 大规模、多环境 |
| **PM2** | 轻量级、易管理 | 隔离性差 | 中小规模 |
| **Nginx + Node** | 简单直接 | 手动管理 | 小规模 |

### 推荐方案
**Docker + Docker Compose**
- 完整的容器隔离
- 易于扩展和维护
- 生产级别的可靠性

## 第5页：Docker部署流程

### 部署步骤

1. **构建镜像**
   ```bash
   docker build -t golden-memory:1.0.0 .
   ```

2. **启动容器**
   ```bash
   docker-compose up -d
   ```

3. **验证部署**

## 第13页：故障排除

### 常见问题

**问题1: 应用无法启动**
- 检查日志: `pm2 logs golden-memory`
- 检查端口: `lsof -i :3000`
- 重新安装: `npm install`

**问题2: 数据库连接失败**
- 检查服务: `systemctl status postgresql`
- 测试连接: `psql -U golden_memory`
- 查看日志: `/var/log/postgresql/postgresql.log`

**问题3: Nginx返回502**
- 检查上游: `curl http://localhost:3000`
- 验证配置: `nginx -t`
- 查看日志: `/var/log/nginx/error.log`
